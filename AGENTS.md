# Codex Project Instructions

Read [`CLAUDE.md`](CLAUDE.md) before starting work in this repository. It is the complete, authoritative project instruction set for Codex as well as Claude Code.

Apply every requirement in `CLAUDE.md` to Codex exactly as a project requirement, including all rules phrased as “Claude MUST” or “Claude MUST NOT.” Interpret references to Claude or Claude Code as referring to Codex or the agent currently working in this repository. Do not treat `CLAUDE.md` as optional background or as instructions only for Claude Code.

For task-specific detail, consult the authoritative documentation linked from `CLAUDE.md` when relevant. Keep `CLAUDE.md` as the source of truth for shared project guidance; update this file only if the Codex handoff itself needs to change.
